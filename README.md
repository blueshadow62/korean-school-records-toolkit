현재 버전은 `1.1.0`이다.

학교생활기록부 초안 생성, 한국어 맞춤법 교정, 글자 수·NEIS Byte 계산을 한 설치 단위로 제공하는 Codex·Claude Code 겸용 스킬 플러그인이다. 세 기능은 서로 병합되지 않으며 각 스킬의 기존 이름·역할·안전 계약을 유지한다.

## 포함 스킬

| 스킬 | 역할 | 주요 호출 범위 |
|---|---|---|
| `write-school-records` | 실제 관찰·평가 근거 기반 학생부 초안·점검 | 세특, 창체 특기사항, 행특, 기재요령 검사 |
| `korean-character-count` | 결정론적 글자 수·줄 수·UTF-8/NEIS Byte 계산 | 분량 확인, 문장·셀별 집계, 최대 한도 검사 |
| `korean-spell-check` | 의미 보존형 맞춤법·띄어쓰기·문장부호 교정 | 최종 교정과 변경 근거 제시 |

여러 기능을 함께 요청하면 `학생부 초안 → 맞춤법 교정 → 글자 수·NEIS Byte 확인` 순서로 연계한다. 한 기능만 요청하면 다른 스킬을 강제로 실행하지 않는다.

## 사용 예시

### 학교생활기록부 작성

> 첨부한 학생별 교사 관찰과 결과물을 근거로 교과 세부능력 및 특기사항 초안을 작성해 줘. 사실이 확인되지 않는 내용은 추가하지 말고, 최종 문장의 글자 수와 NEIS Byte도 확인해 줘.

### 글자 수 확인

> 아래 문장의 글자 수와 NEIS 기준 Byte를 계산하고 1,500Byte 초과 여부를 알려줘.

### 맞춤법 교정

> 아래 세특 문장의 사실 내용과 학생부 문체를 유지하면서 맞춤법과 띄어쓰기만 교정해 줘. 변경한 부분도 알려줘.

### 통합 처리

> 첨부한 학생 자료로 세특 초안을 작성하고, 맞춤법을 교정한 뒤 최종 글자 수와 NEIS Byte를 계산해 줘.

## 안전 원칙

- 이 도구를 활용하실 때에는 근무하시는 시도교육청의 AI 활용 지침 등을 확인하시기 바랍니다.
- `write-school-records`는 CC BY-NC-SA 4.0 라이선스(© 2026 류기현, 부산 동아공고)이며, 비영리 목적에 한해 원저작자 표시·동일조건변경허락 조건으로 자유롭게 사용·수정·재배포할 수 있다. 상업적 이용은 금지되며 문의는 이 저장소의 GitHub Issue로 한다.
- 실제 학생 자료를 예제·테스트·패키지에 포함하지 않는다.
- 배포 전 학생 이름, 학번, 학교명 등 개인정보를 제거한다.
- 테스트에는 합성 자료만 사용한다.
- 학생부 결과는 교사가 원자료와 학교 규정에 대조해 최종 확인한다.
- 플러그인은 학생 사실을 임의로 만들지 않는다.
- 맞춤법 교정은 사실 의미를 변경하지 않는다.
- 맞춤법 검사는 Nara/PNU 공개 웹 표면과 네트워크에 의존한다. 외부 실행 승인이 거부되거나 서비스가 실패하면 검사 미완료로 안내하며, 이를 오류 없음이나 성공으로 처리하지 않는다.
- 실제 학생 자료를 외부 맞춤법 서비스에 보내기 전에 사용자가 개인정보와 전송 가능 여부를 확인한다.
- 분량 계산은 기록의 사실성을 대신하지 않는다.
