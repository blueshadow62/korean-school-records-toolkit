# write-school-records: 국어과 성취수준(A~E) 원문 참조 추가 — 설계

- 날짜: 2026-08-08
- 대상 스킬: `write-school-records` (개발 원본: `skills/write-school-records/`, 공개 패키지: `plugins/korean-school-records-toolkit/skills/write-school-records/`)
- 상태: 파일럿 설계 (국어과 공통과목 한정)

## 배경

사용자가 "2022 개정 교육과정에 따른 성취수준(통합본)" 등 교육부/한국교육과정평가원 계열 연구보고서(PDF→MD 변환본, 국어과 포함 총 30여 과목 분량, 원본 합계 약 180MB)를 제공하며 `write-school-records`를 업그레이드할 수 있는지 문의했다.

이 보고서들은 과목·성취기준·영역 단위로 A~E 성취수준을 실제 서술형 문장으로 정의하고 있어, 현재 `references/curriculum-2022.md`·`references/subject-*.md`의 요약 수준보다 훨씬 구체적인 공식 어휘·서술 강도를 제공할 수 있다.

## 목표

1. 세특 문장에 쓰는 어휘·서술 강도가 해당 과목의 공식 A~E 성취수준 서술과 더 정합하도록 한다.
2. 장기적으로 `subject-*.md`가 다루지 않는 선택과목까지 커버리지를 넓힌다. (이번 설계 범위 아님 — 파일럿 검증 후 별도 작업)

## 스코프 (이번 설계)

- **국어과 전체 10개 과목**: 공통국어1, 공통국어2, 화법과 언어, 독서와 작문, 문학, 주제 탐구 독서, 문학과 영상, 직무 의사소통, 독서 토론과 글쓰기, 매체 의사소통 — "2022 개정 교육과정에 따른 성취수준(통합본).md" 1개 파일 안에 로마자 번호(Ⅲ~Ⅹ)로 구분되어 모두 들어있다(과목마다 번호가 새로 시작하므로 자동 파싱이 아니라 직접 확인한 경계를 사용한다).
- 나머지 29개 과목 파일(수학·영어·사회·역사 등, 서로 다른 파일)은 이 설계에 포함하지 않는다. 이번 파일럿 검증 후 같은 패턴을 반복 적용하는 별도 스펙으로 진행한다.

## 저작권 확인 결과 — 중요한 제약

원본 자료(NCIC 국가교육과정정보센터, `ncic.re.kr`)에서 공공누리 등 명시적 재배포 허용 라이선스를 확인하지 못했다. 사이트 하단에는 `Copyright(C) 2026 by NCIC. ALL RIGHTS RESERVED.`만 표시되어 있다.

**따라서 원문 텍스트는 공개 GitHub 저장소(`plugins/korean-school-records-toolkit/`)에 커밋하지 않는다.** 라이선스가 별도로 확인되기 전까지는 로컬(비공개) 참조로만 존재한다.

## 설계

### 1. 저장 위치 — 로컬 전용

`skills/write-school-records/`(개발 원본)는 현재 git 저장소 바깥에 있고, git 저장소는 `plugins/korean-school-records-toolkit/`뿐이다. 새 참조 자료는 **개발 원본에만** 추가하고 공개 저장소 쪽에는 복사하지 않는다. 새로운 "로컬 전용" 메커니즘을 만들 필요 없이, 이미 존재하는 이원 구조(개발 원본 vs 공개 패키지)를 그대로 이용한다.

라이선스가 나중에 확인되면, 이 참조 파일들을 공개 패키지 쪽으로 복사 + 커밋하는 것은 별도의 후속 작업으로 처리한다.

### 2. 내용 구성 — 원문 그대로, 과목 단위로 분할

- `통합본.md`에서 이미지 참조 줄(`![image](...)`, 약 123MB 상당의 스캔 이미지 대응분)은 제거하고 텍스트만 추출한다.
- 원문에 마크다운 제목 구조(`##`)가 없어 자동 분할이 어려우므로, 수동으로 과목(공통국어1 / 공통국어2) 경계를 찾아 파일을 나눈다.
- 문장은 요약·재작성하지 않고 원문을 그대로 보존한다 — 공식 용어 정합성이 목적이므로 패러프레이즈는 취지에 반한다.

경로:

```
skills/write-school-records/references/achievement-standards/
├── index.md                     # 과목별 파일 안내 (색인) + 공통 성취수준 개념 설명
└── korean/
    ├── 공통국어1.md
    ├── 공통국어2.md
    ├── 화법과_언어.md
    ├── 독서와_작문.md
    ├── 문학.md
    ├── 주제_탐구_독서.md
    ├── 문학과_영상.md
    ├── 직무_의사소통.md
    ├── 독서_토론과_글쓰기.md
    └── 매체_의사소통.md
```

### 3. SKILL.md 연결

- 기존 "최소 참조 라우팅" 표에 한 줄 추가: 국어 세특 요청이면서 성취수준 표현 정합성이 필요한 경우에만 `achievement-standards/index.md`에서 과목을 확인하고 해당 파일 하나만 읽는다. 모든 국어 요청마다 자동으로 읽지 않는다 (기존 "최소 참조" 원칙 유지).
- 근거 등급은 기존 `curriculum_basis`(성취기준·수업 목표) 그대로 사용한다. 학생의 실제 행동·성취 사실은 지금과 동일하게 교사 관찰(`teacher_observation`) 등 기존 근거에서만 나온다. 이 자료는 그 사실을 서술할 때 **공식 성취수준 어휘·강도에 맞추는 용도**로만 쓰이며, 학생의 성취수준(A~E)을 이 자료를 근거로 단정하거나 새로 만드는 데 사용하지 않는다.

### 효과 예시

기존: "논증 구조를 파악함"
개선: 공통국어1 A수준 원문 서술("논증의 타당성을 체계적으로 분석하고...")과 어휘·강도를 맞춘 표현.

## 테스트

- `skills/write-school-records/scripts/test_skill_integration.py`에 다음을 확인하는 테스트를 추가한다: 국어 성취수준 참조가 `curriculum_basis` 등급으로만 취급되고, 학생 성취 사실을 새로 만드는 데 쓰이지 않는다는 계약이 SKILL.md 문면에 명시되어 있는지.
- 새 참조 파일이 로컬 전용임을 확인하는 점검(예: 공개 패키지 경로에 해당 파일이 없는지 확인하는 스크립트/테스트)은 이번 파일럿에서는 수동 확인으로 충분하며, 다음 단계(29개 과목 확장)에서 자동화 여부를 재검토한다.
