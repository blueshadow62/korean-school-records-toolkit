# NEIS 계산 대조용 합성 표본

이 폴더는 실제 학생 기록이 아닌 중립적인 합성 문자열로 로컬 계산값과 실제 NEIS 화면 표시값을 대조하기 위한 자료다. 자동 접속·자동 입력·로그인 정보 사용은 하지 않는다.

## 측정 절차

1. `cases.json`의 `text`를 한 사례씩 복사한다.
2. 실제 업무 기록이 저장되지 않는 빈 테스트 환경 또는 임시 입력 상태에서 NEIS의 테스트 가능한 입력란에 붙여 넣는다.
3. 화면에 표시된 글자 수·Byte·기타 단위를 기록하고, 표시 단위를 함께 적는다.
4. 세특·창체·행특 중 측정한 입력 영역과 측정일을 실제값과 같은 사례에 함께 기록한다.
5. 입력 자료는 저장하지 않고 취소한다. 자동 저장 가능성이 있으면 사용하지 않는다.
6. 기록은 다음 명령으로 원자적으로 반영한다.

```powershell
python .\scripts\compare_neis_counts.py `
  --cases .\tests\neis-validation\cases.json `
  --record case-001 `
  --actual 3 `
  --unit Byte `
  --input-area "세부능력 및 특기사항" `
  --measured-at 2026-07-23
```

## 1단계 우선 측정 세트

다음 15건만 먼저 측정해도 된다: `case-001`~`case-015`.

`case-012`, `case-013`, `case-015`는 세특 입력란, `case-014`는 행특 입력란에서 기록한다. 두 입력란의 계산 방식이 같다고 가정하지 않는다.

화면 구조나 버튼 이름은 확인 전까지 추측하지 않는다. 실제값이 충분히 수집되기 전에는 어떤 계산 방식도 최종 계약으로 확정하지 않는다.
