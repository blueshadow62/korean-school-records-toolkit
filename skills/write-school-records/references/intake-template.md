# 교사 입력 템플릿

## 목차

- 사용 범위
- 개인정보 안내
- 학생 1명용 서식
- 엑셀·CSV 일괄용 열 정의
- 출처 유형 매핑 규칙
- 필수·선택 필드

## 사용 범위

이 문서는 교사가 세특·창체·행특 초안 생성을 요청할 때 자료를 어떤 형식으로 정리하면 [SKILL.md](../SKILL.md)의 「작성 절차」가 출처 유형(`teacher_observation`, `student_product`, `student_self_report`, `assessment_result`, `shared_class_context`, `curriculum_basis`, `supporting_lens`)을 정확히 인식하는지 정의한다. 서식 자체는 자료를 만들지 않으며, 빈 항목은 빈 채로 둔다.

## 개인정보 안내

학생 이름·학번·학교명은 입력할 필요가 없다. 초안 생성과 근거 판정에는 학년·영역·과목(활동)명과 자료 내용만 필요하다. 식별 정보가 포함된 자료를 전달했다면 초안에는 반영하지 않는다.

## 학생 1명용 서식

```markdown
## 기본 정보
- 학년: [예: 2학년]
- 영역: [세특 | 창체-자율·자치 | 창체-동아리 | 창체-진로 | 창체-봉사(3학년) | 행특]
- 과목·활동명: [과목명 또는 활동명]

## 교사 관찰 (teacher_observation)
- [관찰함/확인함으로 명시한 문장만 이 항목에 적는다]
- 예: [교사가 직접 관찰한 행동을 서술]

## 결과물 요약 (student_product)
- 결과물 종류: [보고서 | 발표자료 | 실험노트 | 기타]
- 요약: [결과물에서 확인되는 특징을 서술]
- 검토 여부: [교사가 검토했는지 여부]

## 평가 결과 (assessment_result)
- 평가 종류: [수행평가 | 루브릭 | 기타 교사 평가]
- 결과: [점수·등급·평가 코멘트]

## 학생 소감·자기평가 (student_self_report)
- [학생이 작성한 소감·자기평가·진로 진술을 그대로 붙여넣기]

## 공통 수업 맥락 (shared_class_context)
- 공통 활동 내용: [학급·모둠 단위로 실제 진행된 활동]
- 이 학생의 참여 확인 여부: [확인됨 | 미확인]

## 성취기준·수업 목표 (curriculum_basis)
- [해당 단원·활동의 성취기준 또는 수업 목표]

## 진로 연계 요청 (supporting_lens)
- [진로·전공 연계를 반영하고 싶다면 희망 방향만 기재. 사실을 만들지는 않는다]

## 기타 확인 필요 사항
- [교사가 추가로 확인해 줄 내용이 있다면 기재]
```

빈 항목은 지우지 말고 빈 채로 남긴다. 항목이 비어 있으면 해당 출처 유형의 자료가 없는 것으로 처리한다.

## 엑셀·CSV 일괄용 열 정의

한 행이 학생 1명(또는 학생×영역 1건)에 대응한다. 헤더는 아래 한국어 열 이름을 그대로 사용하는 것을 권장하며, 시스템 연동이 필요하면 괄호 안 영문 키를 열 이름으로 써도 된다.

| 한국어 열 이름 | 영문 키 | 매핑되는 출처 유형 |
|---|---|---|
| 학년 | grade | (분류용, 출처 유형 아님) |
| 영역 | field | (분류용, 출처 유형 아님) |
| 과목·활동명 | subject_activity | (분류용, 출처 유형 아님) |
| 교사 관찰 | teacher_observation | `teacher_observation` |
| 결과물 요약 | student_product | `student_product` |
| 평가 결과 | assessment_result | `assessment_result` |
| 학생 소감/자기평가 | student_self_report | `student_self_report` |
| 공통 수업 맥락 | shared_class_context | `shared_class_context` |
| 성취기준/수업 목표 | curriculum_basis | `curriculum_basis` |
| 진로 연계 요청 | supporting_lens | `supporting_lens` |
| 기타 확인 필요 사항 | teacher_note | (분류용, 출처 유형 아님) |

## 출처 유형 매핑 규칙

1. 열 이름이 위 표의 한국어 열 이름 또는 영문 키와 일치하면 해당 출처 유형으로 처리한다.
2. 열 이름이 표와 일치하지 않거나 해당 열 자체가 없으면 그 내용은 "출처 미확인"으로 두고, [SKILL.md](../SKILL.md) 「작성 절차」의 내부 근거 판정에서 가장 보수적인 등급을 적용한다.
3. 자유 문장으로 입력된 자료(서식 없이 붙여넣은 메모 등)에서는 교사가 "관찰함" 또는 "확인함"이라고 명시한 부분만 `teacher_observation`으로 인정한다. 그 외 서술은 출처가 명시되지 않는 한 `teacher_observation`으로 승격하지 않는다.
4. 한 열에 여러 출처 유형의 내용이 섞여 있으면 전체를 그 열에 매핑된 단일 출처 유형으로 처리하지 않고, 문장 단위로 위 규칙을 다시 적용한다.

## 필수·선택 필드

**최소 필수 필드**

- 학년
- 영역
- 과목·활동명
- 교사 관찰 또는 결과물 요약 중 최소 하나

위 네 가지가 채워지지 않으면 학생별 근거가 없는 것으로 보고 [output-skeleton.md](output-skeleton.md)의 D 판정 전용 골격을 따른다.

**선택 필드**

- 평가 결과
- 학생 소감·자기평가
- 공통 수업 맥락
- 성취기준·수업 목표
- 진로 연계 요청
- 기타 확인 필요 사항

선택 필드는 있으면 근거 폭을 넓히는 데 쓰이지만, 없다고 해서 초안 생성을 막지 않는다.
