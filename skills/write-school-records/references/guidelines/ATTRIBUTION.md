# 고등학교 기재요령 자료의 출처와 이용 안내

## 이 폴더의 파일

| 파일 | 성격 | 배포본 |
|---|---|---|
| `summary.md` | 교육부 원문을 바탕으로 이 스킬이 직접 정리한 핵심 규정 요약. 원문이 아니다 | 포함 |
| `analyzer-rules/` | `scripts/analyze_record.py`가 쓰는 학년도별 검사 규칙(한도·금지 표현 후보) | 포함 |
| `index-terms.json` | 원문을 등록할 때 색인을 만드는 검색어 목록 | 포함 |
| `current.md`, `versions/`, `current.index.md`, `manifest.json` | 원문 PDF를 Markdown으로 바꾼 변환본, 그 보관본과 색인, 등록 기록 | **포함하지 않음.** 개발본에만 있거나 사용자가 직접 등록한다 |

공식 효력을 갖는 것은 교육부가 배포하는 원문 PDF다. 요약이나 변환본과 원문의 내용이 다르게 보이면 **원문을 따른다.** 규정 해석이 걸린 사안은 요약만으로 확정하지 말고 아래 원문 게시물에서 다시 확인한다.

## 출처 표시

> 본 저작물은 교육부에서 2026년 작성하여 공공누리 제4유형으로 개방한 「2026학년도 학교생활기록부 기재요령 안내」를 이용하였으며, 해당 저작물은 교육부 홈페이지(https://www.moe.go.kr)에서 무료로 내려받으실 수 있습니다.

- 원문 게시물: [2026학년도 학교생활기록부 기재요령 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=316&lev=0&statusYN=W&s=moe&m=030215&opType=N&boardSeq=105372)
- 등록일: 2026-02-19 / 담당부서: 교육부 교육과정운영지원과
- 이 폴더가 다루는 것은 첨부파일 중 `2026 학교생활기록부 기재요령(고등학교).pdf`이다.
- 근거 훈령: 교육부훈령 제555호(2026-02-12 일부개정, 2026-03-01 시행).

## 이용조건

원문은 공공누리 **제4유형**(출처표시 + 상업적 이용금지 + 변경금지)이다.

- 출처를 표시해야 한다.
- 상업적 목적으로 이용할 수 없다.
- 원문을 변형하거나 2차적 저작물을 작성할 수 없다.

## 요약의 성격

- `summary.md`는 원문 해설의 문장을 옮기거나 문단 구성을 따르지 않고, 영역별로 '누가, 누구에게, 무엇을 쓸 수 있고 없는지, 예외와 한도'를 이 스킬의 문장과 표로 정리한 것이다. 한도 수치, 금지 항목과 영역의 이름 같은 사실과 고유 용어는 원문 그대로 쓴다.
- `>` 인용 블록 가운데 「훈령 제○조제○항」으로 시작하는 것은 「학교생활기록 작성 및 관리지침」(교육부훈령) 조문을 그대로 옮긴 것이다. 훈령은 저작권법 제7조 제2호에 따라 보호받지 못하는 저작물이다. 인용은 꼭 필요한 조문으로 한정했다.
- 요약 작성일은 2026-11-19이며, 요약 머리말에 학년도·원문 개정일·게시 주소를 기계가 읽을 수 있는 형태로 적었다.

## 원문 변환본을 등록한 환경(개발본·사용자 등록)

배포본에는 원문 변환본이 없다. 개발본과, 사용자가 원문을 직접 등록한 환경에는 아래 형식으로 바꾼 변환본이 있다. 변환본은 원문 PDF를 그대로 담은 것이 아니므로 이용조건을 판단할 때 이 내역을 함께 확인하고, 다른 사람에게 재배포하지 않는다.

- 개발본의 고등학교 변환본은 PDF를 kordoc 4.2.0으로 Markdown으로 바꾸고, 표를 HTML `<table>` 구조로 재구성하고, 대상 파일이 없어 동작하지 않는 이미지 링크 129개를 지운 것이다. 본문 텍스트는 수정하지 않았다.
- `current.index.md`는 변환본에서 만든 색인이다.

## 원문을 직접 등록하거나 새 학년도로 바꾸기

교육부 게시물에서 원문 PDF를 받아 Markdown(`.md`)으로 바꾼 뒤 등록한다. 변환 방법과 확인할 점은 플러그인 저장소의 `USER_GUIDE.md` 「기재요령 원문을 직접 등록하기」를 따른다.

```bash
python scripts/update_guidelines.py import --input <변환한 .md 파일> --school-year <학년도> --revision-date <개정일 YYYY-MM-DD> --source-title "<원문 제목>" --source-url "<게시물 주소>" --confirmed-official
python scripts/update_guidelines.py activate --version <학년도>_<개정일>
python scripts/update_guidelines.py verify
```

활성 버전과 원문 주소는 이 폴더의 `manifest.json`에 기록된다. 원문을 등록해도 `summary.md`와 `analyzer-rules/`는 자동으로 바뀌지 않는다. 새 학년도 원문이면 요약과 검사 규칙을 따로 갱신해야 하며, 그 절차는 플러그인 저장소의 `docs/guideline-summary-updates.md`에 있다.
