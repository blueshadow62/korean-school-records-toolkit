# 응답 골격

## 목차

- 사용 범위
- 공통 골격(세특·창체·행특)
- D 판정 전용 골격
- 엑셀 일괄 출력 골격

## 사용 범위

이 문서는 [SKILL.md](../SKILL.md) 「출력과 점검」이 정한 순서(`초안 또는 작성 지원 → 활용 근거 → 교사 확인 사항 → 분량`)를 실제 응답 틀로 정리한 것이다. 헤더와 자리표시자만 제공하며 문장 예시는 넣지 않는다. 내부 근거 판정 A–D 코드는 사용자가 자동 판정 결과·근거·스킬 검증을 명시적으로 요청한 경우가 아니면 어떤 골격에도 노출하지 않는다.

## 공통 골격(세특·창체·행특)

```markdown
## [세특 초안 | 창체 초안 | 행특 초안 | 작성 지원]

[근거 범위에서 확인되는 문장. A는 완성도 높은 초안, B는 자료 범위 안내를 덧붙인 초안,
C는 초안과 교사 확인 사항, D는 아래 「D 판정 전용 골격」을 사용한다]

## 활용 근거

| 내용 | 출처 유형 | 확인 수준 |
|---|---|---|
| [초안에 반영한 문장·구절] | [teacher_observation | student_product | assessment_result | student_self_report | shared_class_context | curriculum_basis | supporting_lens] | [확인됨 | 제한적 확인 | 미확인] |

## 교사 확인 사항

- [초안에 반영하지 않았거나 교사 확인이 필요한 사실]
- [필요 시 추가 항목]

## 분량

- 글자 수(한글 기준): [◯자] / 한도 [◯자]
- 나이스 Byte: [◯Byte] / 한도 [◯Byte]
- 한도 초과 여부: [초과 없음 | 초과 — 조정 필요]
```

- 「활용 근거」 표의 열 순서는 항상 `내용 → 출처 유형 → 확인 수준` 3열로 고정한다.
- 「분량」 줄의 글자 수·한도는 활성 기재요령([current.md](guidelines/current.md) 「08 학교생활기록부 영역별 입력 가능 최대 글자수」)을 따르며, 참고용 계산은 `scripts/analyze_record.py`로 재확인한다.

## D 판정 전용 골격

학생별 활동·관찰·결과물이 없을 때만 사용한다. 두 문장은 반드시 그대로 포함한다.

```markdown
[학생별 사실 미확인 — 그대로 입력하지 않는 작성 후보]

학생별 관찰·결과가 확인되지 않았으므로 완성형 세특을 생성하지 않습니다.

## 작성 틀

[활동/과제] [교사가 관찰한 행동] [결과물 특징] [피드백 후 변화]

## 관찰 포인트

- 세특: [교과 성취기준과 연결할 수 있는 관찰 포인트 3~5개 중 확인 가능한 것만]
- 창체: [역할·상호작용·공동체 영향과 연결할 수 있는 관찰 포인트 3~5개 중 확인 가능한 것만]
- 행특: [반복 관찰 축(책임 이행·피드백 수용·배려·소통·진로 주도성)과 연결할 수 있는 관찰 포인트 3~5개 중 확인 가능한 것만]

## 교사 확인 질문

- [질문 1]
- [질문 2 — 필요할 때만]
- [질문 3 — 필요할 때만, 최대 3개]
```

- 「작성 틀」의 대괄호 네 항목은 실제 사실이 채워지기 전까지 그대로 대괄호로 둔다.
- 「관찰 포인트」는 영역마다 최소 3개, 최대 5개로 제시한다.
- 「교사 확인 질문」은 최대 3개까지만 제시하고, 더 풍부한 문장을 만들기 위한 질문은 넣지 않는다.

## 엑셀 일괄 출력 골격

```markdown
| 학년 | 영역 | 과목·활동명 | 초안 | 교사 확인 |
|---|---|---|---|---|
| [학년] | [영역] | [과목·활동명] | [세특 초안 또는 D 판정 작성 틀] | [교사가 확인·보완할 사실] |
```

- `초안` 열에는 확인된 근거 범위의 초안 또는 D 판정용 대괄호 작성 틀을 넣는다.
- `교사 확인` 열에는 반영하지 않은 사실, 추가 확인이 필요한 항목을 적는다.
- 사용자가 내부 판정 보고서나 스킬 검증을 명시적으로 요청한 경우에만 별도 진단 시트를 추가한다.

```markdown
[진단 시트 — 요청 시에만 추가]

| 학년 | 영역 | 과목·활동명 | 근거 수 | 비고 |
|---|---|---|---|---|
```
