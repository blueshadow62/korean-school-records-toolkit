# 중학교 기재요령 재가공 참조본의 출처와 이용 안내

## 이 파일들의 지위

이 디렉터리의 `current.md`, `current.index.md`, `versions/`는 **기재요령 원문이 아니다.** 교육부가 공개한 원문 PDF를 근거로 이 스킬이 참조할 수 있는 형식으로 재가공한 참조본이다.

공식 효력을 갖는 것은 교육부가 배포하는 원문 PDF이며, 이 참조본과 원문의 내용이 다르게 보이면 **원문을 따른다.** 규정 해석이 걸린 사안은 이 참조본만으로 확정하지 말고 아래 원문 게시물에서 다시 확인한다.

## 출처 표시

> 본 저작물은 교육부에서 2026년 작성하여 공공누리 제4유형으로 개방한 「2026학년도 학교생활기록부 기재요령 안내」를 이용하였으며, 해당 저작물은 교육부 홈페이지(https://www.moe.go.kr)에서 무료로 내려받으실 수 있습니다.

- 원문 게시물: [2026학년도 학교생활기록부 기재요령 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=316&lev=0&statusYN=W&s=moe&m=030215&opType=N&boardSeq=105372)
- 등록일: 2026-02-19 / 담당부서: 교육부 교육과정운영지원과
- 이 스킬이 사용하는 것은 첨부파일 중 `2026 학교생활기록부 기재요령(중학교).pdf`(173쪽, 4,405,661바이트, SHA-256 `186cfd0355ae64e766640a4df3f7bd94179dc824203edab4c97ef499eaf47578`)이다.
- 근거 훈령: 교육부훈령 제555호(2026-02-12 일부개정, 2026-03-01 시행). 고등학교판과 같다.
- 2026-11-16에 같은 게시판에서 이후 개정·정정 게시물이 없음을 확인했다.

## 이용조건

공공누리 **제4유형**: 출처표시 + 상업적 이용금지 + 변경금지

- 출처를 표시해야 한다.
- 상업적 목적으로 이용할 수 없다.
- 원문을 변형하거나 2차적 저작물을 작성할 수 없다.

## 재가공 내역

원문 PDF를 그대로 담은 것이 아니라 아래와 같이 형식을 바꾼 결과물이다. 이용조건을 판단할 때 이 내역을 함께 확인한다.

- PDF를 kordoc 4.24.30으로 25쪽씩 Markdown으로 변환하고 `## PDF pages a-b` 절로 이었다.
- 표는 HTML `<table>` 구조로 재구성하고, 고등학교 참조본처럼 표의 한 행을 한 줄에 두었다(태그 사이 공백만 정리).
- 그림 추출을 끄고 변환했으며, 남은 그림 자리 표시를 지웠다.
- 변환 뒤 25쪽 묶음마다 원본 PDF의 글자 층과 한글 수를 대조했다(묶음별 100.2~101.3%).
- `current.index.md`는 위 변환본에서 생성한 색인이다.

본문 텍스트는 수정하지 않았다. 정확한 문구와 최신 게시 상태는 위 원문 게시물에서 다시 확인한다.

## 최신 원문으로 교체하기

학년도가 바뀌거나 개정본이 나오면 위 게시물에서 원문을 직접 내려받아 등록한다. 중학교판은 `--level middle`을 붙인다.

```bash
python scripts/update_guidelines.py --level middle import --input <파일 경로> --school-year <학년도> --revision-date <개정일> --source-title <제목> --source-url <주소> --confirmed-official
python scripts/update_guidelines.py --level middle activate --version <버전>
python scripts/update_guidelines.py --level middle verify
```

활성 버전과 원문 주소는 이 폴더의 `manifest.json`에 기록된다. 고등학교판(`references/guidelines/`)과 따로 관리한다.
