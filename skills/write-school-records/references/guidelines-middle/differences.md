# 고등학교·중학교 기재요령 차이 (2026학년도)

중학교 초안·첨삭·점검에서 기준으로 삼는다. 아래에 없는 사항은 두 판이 같으므로 공통 규칙을 그대로 적용한다. 괄호 안은 중학교판 원문의 장 제목과 [summary.md](summary.md)(중학교판 요약)의 규칙 번호다.

- 근거: 2026 학교생활기록부 기재요령(중학교)·(고등학교). 두 판 모두 교육부훈령 제555호(2026-02-12 일부개정, 2026-03-01 시행)를 해설한다.
- 대조: 2026-11-16, 작성 시 유의사항·창체·교과학습발달상황·자유학기·독서·행특·기타사항·최대 글자수 표를 장별로 비교했다.
- 이 파일은 차이를 찾아가는 안내다. 규정의 세부는 [summary.md](summary.md)를 보고, 두 문서가 다르게 읽히면 요약을 따른다. 문구가 결과를 가르면 원문이 등록된 환경에서는 원문의 해당 장을 읽고, 최종 효력은 교육부 원문에 있다.

## 1. 공통 금지 사항 (「01 학교생활기록부 작성 시 유의사항」, 요약 2절)

같은 것: 공인어학시험, 교내·외 대회와 수상, 교외상, 인증시험, 논문 투고·등재·학회 발표, 도서 출간, 지식재산권 출원·등록, 해외 활동실적, 부모·친인척의 사회·경제적 지위, 장학금, 구체적인 대학명·기관명·상호명·강사명(교육관련기관 예외 포함), 자격증 명칭·취득 사실, 생성형 AI 자료를 그대로 입력하는 행위, 교사가 직접 관찰·평가한 내용으로 쓰는 원칙.

중학교판에 없는 것:

- 모의고사·전국연합학력평가 성적: '고등학교 관련 내용으로 생략'(요약 2-13).
- 재학(졸업 예정) 학교를 알 수 있는 내용(학교명, 재단명, 학교 축제명, 학교 별칭 등)의 기재 금지 조항. 중학교 기록에는 이 금지를 적용하지 않는다.
- 학교 밖 교육기관의 기관명 대신 기관 유형으로 통칭하는 규정.

## 2. 교과 세부능력 및 특기사항 (「12 교과학습발달상황」, 요약 4절)

| 항목 | 고등학교 | 중학교 |
|---|---|---|
| 입력 대상 | 모든 교과·모든 학생이 원칙. 수업 대부분 미참여 시 학업성적관리위원회 심의로 `특이사항 없음.` | 특기할 만한 사항이 있는 과목·학생에 입력(제15조⑦, 요약 4-5). 입력 대상 범위는 학업성적관리위원회 심의로 정함(요약 4-6) |
| 자유학기 과목 | 없음 | 모든 과목·모든 학생에 입력. 성취수준의 특성, 학습활동 참여도·태도, 활동 내역(체육·예술은 실기능력·교과적성 포함)(제15조⑬, 요약 4-7). 수업에 참여하지 못한 학생은 사유 입력(예: `장기결석으로 특이사항 없음.`). 성취도는 `P`, 과목명 뒤 `(자유학기)` 자동 표기 |
| 쓰는 내용 | 같음: 학생참여형 수업·수행평가 관찰, 성취수준의 특성, 학습활동 참여도, 자기주도적 학습에 의한 변화와 성장(요약 4-1). 체육·예술(음악/미술)은 실기능력·교과적성 포함 | 같음 |
| 학기 구분 | 학기별로 입력 | 학기별로 입력할 수 있음. `(1학기)`, `(2학기)` 자동 표기 |
| 한도 | 과목별 500자, 공통과목 1·2 합산 500자, 전공실무과목 학기별 500자 | 과목별 500자. 합산·학기별 규정 없음 |
| 연구보고서(소논문) | 금지. 단 과제탐구 계열 과목은 실적(제목·주제·인원·시간)을 빼고 기재 가능 | 예외 없이 금지(요약 4-14) |

같은 것: 입력 금지 항목(유의사항 금지 사항, 대회 참여·성적·수상과 그 명칭을 행사로 바꿔 쓰기, K-MOOC 등, 방과후학교 활동), 학생건강체력평가(PAPS) 1등급의 체육 관련 세특 기재(요약 4-4). 영재교육은 두 판 모두 별도 기록사항에 쓰지만, 발명교육은 중학교판에서 관련 교과 세특 본문에 쓴다(요약 4-15, 4-16).

고등학교에만 있는 것: 전문교과 능력단위 기재, 3학년 2학기 내용의 대입 미반영 안내, 공통과목 최소 성취수준 보장지도.

## 3. 창의적 체험활동상황 (「10 창의적 체험활동상황」, 요약 5절)

- 영역별 이수시간 없이 특기사항만 입력한다(제13조②, 요약 5-1). 특기사항은 모든 학생에 대해 영역별로 우수한 사항과 실제 역할·활동 중심으로 쓴다(요약 5-6). 한도는 자율·자치(3학년은 자율)·동아리·진로 각 500자, 봉사활동 실적의 활동내용은 실적별 50자로 고등학교와 같다.
- 동아리활동 입력 항목은 5가지다(요약 5-18): 정규 동아리 `(영어회화반) ~`, 자율동아리 `(로봇반: 자율동아리)`, 청소년단체 `(○○단: 청소년단체)`, 정규교육과정 내 학교스포츠클럽 `(발야구반: 학교스포츠클럽) ~`, 방과후학교스포츠클럽(클럽명만). 괄호 안의 부서명과 유형 표기는 시스템이 자동으로 넣으므로 특기사항 본문에 다시 쓰지 않는다(요약 5-18).
- 정규교육과정 내 학교스포츠클럽활동은 동아리활동으로 편성하고, 참여한 모든 학생에 대해 담당 교사가 개별적 특성이 드러나도록 입력한다(요약 5-21). 고등학교에는 해당하지 않는다.
- 학교교육계획에 따른 청소년단체활동은 단체명만 입력하고, 학교교육계획 밖의 청소년단체활동은 어떠한 내용도 입력하지 않는다(제13조⑪, 요약 5-20).
- 입력할 수 있는 체험활동: 학교가 주최·주관한 국내 활동, 학교장이 승인한 타 중학교·교육관련기관 주최 활동. 고등학교나 외부기관(시민단체 포함)이 주최한 활동은 입력할 수 없다(요약 5-10, 5-12). '학교 밖 교육'은 해당하지 않는다.
- 정규교육과정에 따라 해외에서 실시한 창의적 체험활동은 특기사항을 입력하지 않는다(요약 5-14).
- 1~2학년은 창의적 체험활동 영역과 연계한 봉사활동의 특기사항을 해당 영역에 쓸 수 있다(고등학교와 같다).

## 4. 자유학기활동상황 (「13 자유학기활동상황」, 요약 6절, 중학교에만)

영역별 한도 1,000자. 작성 기준은 [field-free-semester.md](../field-free-semester.md)를 따른다.

2026학년도 3학년이 자유학기를 일반학기로 연계 운영하는 학교라면, 중점 연계형 자유학기활동은 운영한 시간에 따라 해당 교과 세특이나 창체 영역 특기사항에 `(프로그램명)`을 직접 붙여 쓴다(요약 5-25). 동아리명은 자동 입력되므로 다시 쓰지 않는다.

## 5. 행동특성 및 종합의견, 독서활동상황

- 행특(「15 행동특성 및 종합의견」, 요약 7절): 같다. 300자.
- 독서활동상황(「14 독서활동상황」, 요약 9절): 같다(공통 500자, 과목별 250자). 단순 독후활동 외의 교육활동은 세특·창체에 더해 자유학기활동상황에도 쓸 수 있다.

## 6. 영역별 입력 가능 최대 글자수 (「07 학교생활기록부 영역별 입력 가능 최대 글자수」, 요약 8절)

| 영역 | 한도(한글 기준) | 고등학교와 비교 |
|---|---|---|
| 과목별 세부능력 및 특기사항 | 과목별 500자 | 합산·학기별 규정 없음 |
| 개인별 세부능력 및 특기사항 | 500자 | 같음 |
| 창체 자율·자치(3학년은 자율)·동아리·진로 특기사항 | 각 500자 | 같음 |
| 봉사활동 실적 활동내용 | 실적별 50자 | 같음 |
| 자유학기 진로탐색·주제선택·예술·체육·동아리 특기사항 | 각 1,000자 | 중학교에만 있음 |
| 행동특성 및 종합의견 | 300자 | 같음 |
| 독서활동상황 | 공통 500자, 과목별 250자 | 같음 |
| 자격증, 전공·과정 | 항목 없음 | 고등학교에만 있음 |

표에 별표(*)가 붙은 창체·독서·행특의 최대 글자수는 학년 단위다. 한글 1자는 3Byte, 영문·숫자 1자와 엔터는 1Byte다.
