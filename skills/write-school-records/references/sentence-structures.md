# 근거 기반 서술 구조 (S1–S10)

초안 생성·첨삭 때 SKILL.md의 지시에 따라 읽는다. 구조 코드는 내부 계획에만 사용하고 결과에 노출하지 않는다.

초안 전에 가장 구체적이고 확인 수준이 높은 핵심 근거를 고른 뒤, 근거 성격에 맞는 구조를 선택한다. 구조 코드는 내부 계획에만 사용하고 결과에 노출하지 않는다.

| 유형 | 선택 조건 | 전개 |
|---|---|---|
| S1. 구체적 활동 선행형 | 발표·조사·실험·토론·과제가 핵심 | 확인된 활동 → 구체 수행 → 결과·의미 |
| S2. 문제의식·질문 선행형 | 질문·모순·한계·오류를 실제로 제기함 | 문제의식 → 확인·분석 → 사고 특징 |
| S3. 과정 선행형 | 비교·계산·분류·추론·단계 설명이 핵심 | 수행 과정 → 기준·방법 → 확인 결과 |
| S4. 결과물 선행형 | 보고서·발표 자료·표·그래프의 특징이 확인됨 | 결과물 특징 → 이를 만든 수행 → 제한적 해석 |
| S5. 변화·개선 선행형 | 피드백·오류 수정·재작성의 전후가 확인됨 | 초기 상태·피드백 → 수정 행동 → 확인된 개선 |
| S6. 개념 이해·적용형 | 원리 적용·사례 연결·개념 관계 설명이 핵심 | 개념·원리 → 구체 적용·연결 → 확인 성취 |
| S7. 자료 해석형 | 표·그래프·사진·지도·관측·통계 자료가 핵심 | 포착한 특징 → 비교·해석 → 결론·한계 |
| S8. 성찰·관심 선행형 | 소감·자기평가·관심 진술만 확인됨 | 학생이 밝힌 내용 → 근거가 된 내용 → 제한적 의미 |
| S9. 성취 후 보완형 | 확인된 수행과 근거 있는 보완점이 함께 있음 | 확인 성취 → 현재 특징 → 보완 방향 |
| S10. 종합 관찰형 | 복수 교사 관찰과 과정·결과·피드백이 있음 | 핵심 수행 특성 → 대표 근거 둘 이상 → 종합 평가 |

두 유형이 모두 적합할 때만 배치의 반복성을 보조 기준으로 사용한다. 무작위 순환 배정이나 동의어 교체만으로 다양화하지 않는다. 구조가 입력보다 강한 주장을 요구하면 더 보수적인 유형을 선택하고, 근거가 하나뿐이면 복잡한 성장 서사를 만들지 않는다. 결과물만 있는 B 모드는 S4를 사용해도 교사 관찰로 확대하지 않으며, S5·S10은 실제 변화 또는 복수 관찰이 있을 때만 사용한다.

문장은 활동명 외에도 확인된 질문, 자료의 특징, 결과물, 수정 행동, 적용한 개념, 사례 연결, 학생이 밝힌 성찰, 수행상의 강점으로 시작할 수 있다. `○○ 학습에서`, `○○ 발표에서`, `○○ 활동에서`, `○○을 주제로`를 일괄 적용하지 않는다. 마무리는 확인 결과·수정·사고 과정·설명의 구체성·자료 해석·개념 적용·근거 있는 보완 방향 중 근거에 맞게 고른다.

`자료 해석 능력`, `비판적 사고`, `문제 해결력`, `과학적 의사소통 역량` 같은 추상 명사는 대응하는 행동이 먼저 드러나고 같은 의미를 되풀이하지 않을 때만 사용한다. 행동만으로 충분하면 `역량을 보임`, `능력을 보임`, `과정을 드러냄`을 덧붙이지 않는다.

학생이 10명 이상이면 개별 검수 뒤 배치 전체를 점검한다. 동일한 첫 3어절 또는 마지막 서술어가 25%를 넘거나, 한 구조 유형이 40%를 넘거나, `역량을 보임`·`능력을 보임`·`과정을 드러냄` 중 하나가 20%를 넘으면 검토 경고로 다룬다. 핵심 근거가 다른데 동사 배열이 같거나 명사만 교체된 쌍도 찾는다. 이 기준은 재작성 명령이 아니며 실제 근거가 유사하면 구조 반복을 허용한다.

우선순위는 `학생별 사실 → 출처의 표현 강도 → 실제 수업 맥락 → 성취기준 연결 → 기재요령 → 문장 다양성`이다. 다양성을 위해 입력에 없는 질문·발표·피드백·협업·추가 탐구·진로 연계·성장·높은 성취·지속적 태도를 만들지 않는다. 예시 자료에서는 전개 순서, 사실·해석의 연결 방식, 어휘, 표현 강도, 분량 감각만 참고하고 문구·활동·학생 특성을 복사하지 않는다.
