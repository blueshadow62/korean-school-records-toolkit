# 한국어 학교생활기록부 도구 라이트

교사가 직접 관찰·평가한 사실을 근거로 학교생활기록부 서술형 항목의 초안을 쓰고, 이미 쓴 문장을 첨삭·점검하는 스킬입니다. 고등학교와 중학교의 교과 세부능력 및 특기사항(세특), 창의적 체험활동 특기사항, 행동특성 및 종합의견, 중학교 자유학기활동 특기사항을 다룹니다.

이 플러그인은 [한국어 학교생활기록부 도구](https://github.com/blueshadow62/korean-school-records-toolkit)(전체판)에서 스크립트를 뺀 문서 전용판입니다. 스킬 문서와 참고 자료만 들어 있으며 claude.ai, Cowork, Claude Code에서 씁니다.

## 할 수 있는 일

- 교사의 관찰 메모, 검토한 학생 결과물, 평가 결과를 근거로 영역별 초안을 씁니다. 근거가 부족하면 완성 문장 대신 작성 틀과 확인 질문을 드립니다.
- 이미 쓴 문장에서 근거 없는 표현과 기재요령이 금지한 내용(공인어학시험, 대회·수상, 대학명 등)을 찾아 알려 드립니다.
- 2022 개정 교육과정 중·고등학교 성취수준 자료에서 성취기준별 수준 설명을 찾아 표현을 맞춥니다.
- 학교급별 기재요령 요약으로 기재 가능 여부, 입력 주체, 분량 한도를 확인합니다.

## 쓰는 원칙

- 교사가 확인한 사실만 씁니다. 활동, 역할, 성과, 변화를 지어내거나 부풀리지 않습니다.
- 학생이 쓴 소감문·자기평가는 학생의 진술로 다루고, 교사가 관찰한 사실처럼 바꿔 쓰지 않습니다.
- 출력은 교사가 사실과 규정을 대조하기 전의 보조 초안입니다. 기재요령은 생성형 AI로 만든 자료를 서술형 항목에 그대로 입력하지 않도록 하고, 윤문 같은 보조 수단으로 썼다면 최종 입력 전에 허위·과장 여부와 유의사항 준수를 철저히 확인하게 합니다.
- 근무하시는 학교·시도교육청의 AI 활용 지침과, 학생·보호자에게 AI 사용 사실을 알려야 하는지(고지 의무)를 확인하시기 바랍니다. 참고로 Anthropic 사용 정책은 입학 허가·순위 결정, 입학·졸업을 정하는 평가의 채점 같은 교육 분야 결정에 AI를 쓰면 자격 있는 사람의 검토와 당사자에 대한 AI 사용 고지를 요구합니다.
- 학생 이름·학번·학교명 같은 개인정보는 빼고 자료를 주시기를 권합니다.

## 기재요령은 요약을 기준으로 판단합니다

교육부 「2026학년도 학교생활기록부 기재요령」(고등학교·중학교, 2026년 2월 12일 개정)을 바탕으로 이 도구가 직접 정리한 요약으로 규정을 판단합니다. 원문은 들어 있지 않습니다. 공식 효력은 교육부 원문에 있으며, 요약과 원문이 다르면 원문을 따릅니다. 원문은 교육부 홈페이지(https://www.moe.go.kr)에서 받을 수 있습니다. 답변의 분량 절에는 요약을 기준으로 했다는 사실과 바탕이 된 기재요령 판을 적습니다.

## 글자 수와 나이스 Byte

Claude가 코드 실행 도구로 초안 본문의 글자 수와 Byte를 계산합니다(한글 1자 3Byte, 영문·숫자·공백 1Byte, 줄바꿈 1Byte). 코드 실행을 쓸 수 없는 환경에서는 값을 짐작해 적지 않고 '글자 수는 기계로 점검하지 못했습니다'라고 알려 드립니다. 계산값은 참고값이며, 실제 나이스 입력값은 따로 확인해 주십시오.

## 이 판에 없는 기능

다음 기능은 스크립트가 필요해 이 판에 넣지 않았습니다. 필요하시면 Claude Code와 Codex에서 쓰는 전체판(https://github.com/blueshadow62/korean-school-records-toolkit)을 쓰십시오.

- 금지 표현과 분량을 기계로 점검하는 스크립트. 이 판에서는 Claude가 요약을 기준으로 직접 점검합니다.
- 글자 수·줄 수·Byte를 계산하는 별도 스킬
- 교육부 기재요령 원문을 직접 등록해 문구까지 대조하는 기능
- 실제 나이스 입력값 대조와 스킬 행동 검증 도구

두 판을 함께 설치하면 같은 스킬이 두 개 보이므로 하나만 설치하십시오.

## 실행하는 것과 외부 연결

이 판에는 스크립트와 실행 파일이 없고, Markdown과 JSON 문서만 들어 있습니다. 플러그인은 네트워크에 접속하지 않으며, 입력한 학생 자료를 수집하거나 외부로 보내지 않습니다. 글자 수 계산은 Claude의 코드 실행 도구 안에서 스킬 문서에 적힌 몇 줄의 코드로 이루어집니다. 입력한 자료를 어떻게 다루는지는 [개인정보 처리 안내](PRIVACY.md)에 적었습니다.
